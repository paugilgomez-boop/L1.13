# L1.13 – Guía de Sistemas Operativos (Es el ejercicio 1 del video L1.13)

## Qué incluye
- Servidor en C: `4.2.1.c`
- Cliente en C#: solución `Cliente.sln` + proyecto `Cliente/`

## Cómo ejecutar
1. **Servidor (Linux/Ubuntu):**
   - Compilar: `gcc -o servidor 4.2.1.c`
   - Ejecutar: `./servidor`
2. **Cliente (Windows/Visual Studio):**
   - Abrir `Cliente.sln`
   - Ejecutar (F5).  
   - IP y puerto según la práctica (misma red que la VM).

## Funcionalidades implementadas
- Longitud del nombre
- Nombre bonito (M/S)
- Altura (alto/bajo)
- Palíndromo
- Mayúsculas
- Conversión de grados C↔F

## Notas
- Probado con VS 2022 y Ubuntu 16.04 (VM).
- Puerto usado: **9400** (ajustar si lo cambias).
